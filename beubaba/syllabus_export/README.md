# BEU Syllabus Export — for MCQ generation

Generated by `uploads/export_syllabus_for_mcq.py` from the app's syllabus dataset.

## Files
- `index.json` — catalog of all 30 branches with subject/unit counts + file names.
- `<branch>.json` — **one file per branch**, all 8 semesters, every subject, unit-wise topics.
- `_ALL_BRANCHES.json` — everything in a single 5 MB file (optional bulk).

## How to use
1. Open **`docs/QUIZ_MCQ_GENERATION_PROMPT.md`** (the master prompt).
2. Feed the prompt + **one branch file** into your MCQ generator.
3. Get back one `*.mcq.json` per branch (flat array of question objects).
4. Send those files back — they import directly into the quiz engine.

## Coverage
30 branches · 1749 subjects · 1286 subjects with unit-wise detail · 4340 units.
Subjects where `has_detailed_syllabus:false` had no unit content in the BEU
source (mostly labs / a few new branches) — skip or generate from the subject
title only.

> `_ALL_BRANCHES.json` (4.8 MB) was removed to stay inside the workspace size
> limit. It was only the per-branch files concatenated — those are all still
> here, and the same data is live in the database (1,168 syllabus rows).
