PUT YOUR PROMO VIDEOS HERE
==========================

Folder:  beubaba/public/promo/videos/

Expected filenames (each optional — a scene falls back to a still image
if its video is missing):

    01-intro.mp4       app opening / logo animation
    02-home.mp4        home dashboard walkthrough
    03-quiz.mp4        taking an MCQ quiz
    04-notes.mp4       PYQs and syllabus
    05-tools.mp4       toolbox / assistant
    06-profile.mp4     profile and results

Also add a poster image for each so the scene shows something
immediately while the video loads:

    01-intro.jpg, 02-home.jpg, ...

RECOMMENDED ENCODING
    Format   MP4 (H.264 + AAC)
    Size     1080x1920 portrait (phone recordings) or 1920x1080
    Length   5-15 seconds each, looping
    Bitrate  2-4 Mbps
    Target   under 3 MB per file

Keep them small. Six large videos on a phone connection will make the
promo site feel slow, which defeats the purpose.
